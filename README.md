# Display All Prime Numbers from 1 to N

## Description
This program prints all prime numbers from 1 to a given number N. The user is prompted to enter the value of N, and the program calculates and displays all prime numbers up to that number.

## How to Run

### Prerequisites
- Ensure Java is installed on your system.
- You should have a terminal or command prompt to compile and run the program.

### Steps to Execute
1. Save the Java file as `PrimeNumbers.java`.
2. Open a terminal or command prompt and navigate to the project folder.
3. Compile the Java program using:
    ```sh
   javac PrimeNumbers.java
4. Run the program using:
    ```sh
   java PrimeNumbers
5. Enter a number (N) when prompted, and the program will display all prime numbers up to N.
